화면 · 출시 점검

일반 게임과 저장하지 않는 디자인 데모를 분리해 확인합니다. 모든 화면은 같은 게임 파일을 사용합니다.

일반 게임은 실제 진행 상황을 저장하며 해금 조건을 따릅니다. 디자인 데모의 잔액·구매·편성은 저장되지 않습니다. 데모에서만 보이는 MAXED 상태를 실제 저장 데이터로 옮기지 마세요.

출시 전 확인

  • 일반 게임에서 구매 후 다시 열어 잔액·편성·강화가 유지되는지 확인
  • 설정 → 도움말 → 복귀, 전투 → 일시정지 → 재개 확인
  • 나가기·재시작 확인창의 취소가 전투 진행을 바꾸지 않는지 확인
  • 모바일 가로·세로 화면에서 버튼 잘림과 터치 영역 확인
  • 온라인 작업 공간은 공개 게임의 이미지를 읽습니다. 게임 코드와 이미지 배포를 먼저 마친 뒤 작업 공간을 배포하세요.

이 페이지는 점검용이며 게시·보상 변경·진행 초기화를 수행하지 않습니다.
