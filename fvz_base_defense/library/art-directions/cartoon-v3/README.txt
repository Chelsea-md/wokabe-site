카툰 가든 v3 · 팔 포즈와 UI 검토

피드백 근거: 사용자가 전달한 v2 화면과 GIF에서 뒷팔이 몸통에 가려지고, 팝피의 지지 손·당기는 손이 분명하지 않았습니다. UI는 웹 패널처럼 보인다는 의견을 반영했습니다.

수정: 위팔과 아래팔을 분리하고 손 목표 위치에 따라 팔꿈치를 계산합니다. 팝피 10파츠, 모시 8파츠. 승인된 머리·몸통·발은 v2 시트를 재사용합니다. 관절 표시를 켠 동작 실험실에서 대기·공격·피격 및 걷기를 확인할 수 있습니다.

UI 1 아케이드 코믹: 각진 프레임, 하프톤 카드, 원색과 굵은 외곽선.
UI 2 가든 캠프: 나무 표지판, 종이 카드, 잎색 이름표.
UI 3 토이 배틀: 두꺼운 플라스틱 프레임, 돌출 비용 버튼, 둥근 카드.
같은 장면에서 색·형태·구매 카드·버튼 깊이를 비교합니다. 시안 버튼을 누르면 장면이 초기화되고 정지합니다.

이미지 리소스: Built-in ImageGen으로 제작한 RGBA PNG. UI 프레임은 HTML/CSS, 전장과 리깅은 Canvas 코드입니다. 다른 캐릭터는 아직 단일 포즈입니다. 이 프리뷰는 최종 전투 로직·밸런스·최종 애니메이션이 아닙니다.

묶음: rigs.json, rig-renderer.js 및 assets/의 v2 기본 시트 2장 + v3 팔 시트 2장. atlas 경로는 묶음 내 상대 경로로 조정했습니다.
