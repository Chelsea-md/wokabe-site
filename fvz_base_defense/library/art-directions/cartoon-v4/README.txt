GARDEN CAMP × TOY BATTLE — v4

Warm wood, cream paper and leaf-green palette on rounded toy frames. Core UI icons and six English title labels are raw ImageGen RGBA atlases. Numeric values remain live text using the existing game typeface. All v4 in-game text is English. The surrounding review page is Korean.

Poppy: shorter torso and legs, larger head share, screen-left shoulder and arm drawn above torso/head; elbow remains outside the left body edge during pull.
Mossy: inset shoulders, upper sleeve overlap on torso, solid orange fabric caps replacing green exposed joint surfaces.

Only Poppy and Mossy use part animation. Remaining characters are static sprites. Motion and gameplay are review prototypes.

Resource pack includes four rig atlases, two UI atlases, rigs.json, renderer, UI source rectangles, and production prompts. UI lettering is an image label set, not a font file. All supplied PNG transparency preserved.
