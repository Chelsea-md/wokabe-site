production-9 첫 진입과 화면 바깥 정리 · 2026-10-18

첫 HTML에 승인된 로고 아틀라스의 SVG 뷰를 포함하고 이미지를 우선 로드한다. 로고가 로드된 순간 부드럽게 나타나며 통통 움직이고, 준비된 홈으로 260ms 동안 사라진다. 게임 모듈 로딩 전에도 로고를 표시한다. 동작 줄이기를 선택한 환경에서는 모션과 추가 대기 없이 진행한다.

PLANTS 캐릭터 영역을 94%×82%에서 80%×72%로 줄이고 발밑에 부드러운 타원 그림자를 둔다. 이름표 위 여백을 확보하며 기존 idle 모션과 그림자 호흡 주기를 맞춘다.

모든 화면 바깥 여백을 짙은 녹색 #142e26으로 통일한다. 모바일을 포함해 2:1 가로형 게임을 화면에 맞춰 가운데 배치한다. 세로형 UI, 자동 화면 회전, 가로 회전 안내는 추가하지 않는다. 이전 버전의 화면비에 따른 배경색 분할·미세 늘림 정책은 대체한다.

production-8 배치·합성 상태 정리 · 2026-10-18

최신 사용자 결정: CHILI 기본 지급, ACORN/PINECONE은 1스테이지부터 코인 구매, SUNFLOWER는 3스테이지 진입부터 구매한다. 기존 구매는 보존하며 후속 캐릭터를 추가하는 방향이다. 아래 이전 버전의 3/6/9 조건은 이력으로 대체되었다.

카드 이름표·정보 패널·초상의 발 기준선을 정렬했다. 드래그의 상대 위치와 단일 보간 경로를 유지하며, 선택한 칸은 그리드 위에 채워진다. 범위는 손을 떼면 80ms 내 제거, 합성 후보 표시는 잡고 있을 때만 유지한다. 꽉 찬 보드의 잘못된 재배치를 거절하고 정상 합성은 허용한다.

합성된 유닛 한 명에만 짧은 확대와 코드로 그린 노란 빛·입자를 표시하며 합성 이미지 에셋은 사용하지 않는다. 카운트다운 중 시각 수명이 멈추던 문제를 고쳤다. 홈의 기지 조명과 가장자리 배경을 보완하고 구매 불가 시 비용 버튼만 비활성 색으로 표시한다. 카운트다운은 작게, 대기 중 화살표는 숨김 처리한다.

production-7 화면 정리 · 2026-10-18

최신 사용자 피드백으로 큰 합성 빛 기둥/문자 에셋을 끄고 작은 캐릭터 확대만 남겼다. 범위는 촘촘한 둥근 점선, 줌아웃 가장자리는 이어진 지형, 햇빛은 더 밝은 노란 채움, 웨이브는 처치 진행 끝을 가리키는 작은 흰 화살표로 표시한다.

최초 로고 스플래시만 표시하고 START/홈 복귀의 중간 스플래시는 생략한다. PLANTS 카드를 약15% 줄이고 무료 보너스도 불가한 업그레이드는 회색 disabled 처리한다. 모든 활성 버튼에 깊은 눌림 반응을 적용하며 양측 발사체는 실제 이동 경로의 꼬리와 방향을 표시한다. 아래 production-6 합성 에셋 기록은 이전 버전의 이력이다.

production-6 본편 반영 · 2026-10-18

최신 본편은 6개 맵 확장 루트, 반복 회차 난도 증가, 근거리 석궁 엘리트, SUNFLOWER 10성 외형, 부드러운 드래그와 상시 합성 가능 입자, 첫 합성 안내, FREE 버튼 모션을 사용한다. 이전 절의 원본 관찰은 근거로 보존하며 최신 역할 변경은 사용자 지시를 따른다.

합성 시 노란 빛 기둥·LV UP와 작은 확대 강조를 표시한다. 휠 줌은 96~112%이며 UI는 확대하지 않는다. 웨이브와 햇빛 표시판 내부가 차오른다. 기존 첫 세 맵의 저장 인덱스를 보존하고 Moonblock→Oasis Cross→Noon Strip을 확장 루트로 추가했다. 새 맵 순서·웨이브 수치·18% 반복 난도 증가는 우리 게임의 조정값으로 원본 실측 확정값이 아니다.

게임이 지켜야 할 원칙

  • 첫 화면에서 로그인 없이 게스트로 시작할 수 있다.
  • 게임 안의 제목·버튼·능력치·안내·알림·일시정지 문구는 모두 영어로 제작한다. 프리뷰 바깥의 설계 설명은 한국어를 유지한다.
  • 캐릭터 스킨을 바꾸더라도 원본의 화면 구조·8칸 배치·드래그 구매·합성 판단을 유지한다.
  • 병력을 재배치하고 사거리를 확인하는 조작이 전투 중에도 가능하다.
  • 현재 전투의 자원과 다음 도전까지 남는 코인을 분리한다.
  • 확인된 원본 규칙과 재제작의 보정값을 구분해서 관리한다.

웨이브별 인원·간격·보스 위치와 보상은 챕터 데이터로 분리한다. 원본에서 확인하지 못한 챕터 이름이나 무한 진행을 임의의 확정 콘텐츠로 추가하지 않는다.

Moonblock 기록은 고체력 사신형 적의 등장으로12자원 병력의 체감 가치가 올라간 사례다. 후반 난도는 적의 구성과 교전 조건으로 병력 선택의 이유를 바꾸는 방향을 검토한다. 정확한 수치와 역할 조정은 사거리·발사 간격·공격 유지 시간을 대조한 뒤 결정한다.

Forest Camp 관찰은 원거리 적 증가를 챕터 변주의 후보로 추가한다. 병력 선택에 영향을 주는 축으로 적의 체력, 공격 거리, 진입 방향을 분리해 검증한다. 공격 범위 표시와 적 투사체의 식별성을 함께 검토하며, 관찰만으로 특정 병력 상향이나 적 능력치를 확정하지 않는다.

Oasis Cross에서는 적이 나오는 속도가 빨라졌다는 사용자 관찰을 기록했다. 챕터별 난도 요소를 적 체력·공격 거리·등장 간격·묶음 크기·이동 속도로 나누어 비교한다. 아직 측정한 변화는 아니며, 클리어 보상과 전체 웨이브 구성도 미확정이다.

조작 감각과 표시 기준

  • 식물과 사거리 원은 같은 시각 위치를 부드럽게 따라간다.
  • 유효 칸은 초록색, 합성할 수 없는 점유 칸은 다른 강조색으로 구분한다.
  • 카드를 드래그하는 동안 해당 구매 카드의 그림을 숨긴다.
  • 드롭 후 약0.22초 안착 효과와 짧은 크기 변화를 사용한다.
  • 체력바와 작은 레벨 표식은 손상된 병력에만 표시한다.
  • 설정 창은 전투와 자원 생산을 멈춘다. 시작 버튼은 마우스를 올리면 커진다.

완료 기준과 남은 결정

  • 동일한 화면 크기와 상태로 원본과 나란히 비교한다.
  • 마우스와 터치에서 구매·합성·이동·취소·범위 표시가 동작해야 한다.
  • 두 챕터의 결과·선택형 보상·다음 홈·재접속을 검사한다.
  • 합성 체력·타깃 선택·레벨 성장·정산 잔액 차이는 확인 전까지 열린 항목으로 둔다.
  • 라이브러리의 검토 상태를 바꾼 것만으로 게임 전체 검증을 통과 처리하지 않는다.

비주얼 제작 기준 · 사용자 레퍼런스

2026년10월17일에 제공된 캐릭터·UI9장과 적 디자인5장을 기준으로 카툰 방향을 보강한다. 굵은 진한 외곽선, 둥글고 과장된 실루엣, 선명한 색면과 익살스러운 표정이 중심이다. 기존 C/U 시안 번호의 선택이나 최종 승인으로 처리하지 않는다.

  • 일관된 굵기의 진한 외곽선과 단순한 색면
  • 둥글고 과장된 체형, 큰 표정, 한눈에 읽히는 실루엣
  • 밝은 아군 색·차분한 배경·구별되는 적의 포인트 색
  • 유닛이 실제 전장 크기로 작아져도 병종·성장 단계·적 역할이 구별됨
  • 큼직한 버튼, 아이콘 중심 카드, 일관된 프레임과 숫자 위계
  • 기존 중앙 기지·주변8칸·상단 상태·하단 구매 영역 유지

  • 일반형: 작은 체형과 단순한 걸음 동작
  • 원거리형: 투사체와 연결되는 큼직한 소품·공격 예고
  • 탱커형: 넓은 몸통과 느린 무게감, 일반형보다 큰 실루엣
  • 보스형: 고유 실루엣과 공격 예고. 크기와 색만으로 모든 상태를 전달하지 않음
  • 익살스러운 좀비 표정, 적당한 비대칭과 낡은 소품

일반형·원거리형·탱커형은 실제 전장 크기로 축소해 비교한다. 도감이나 확대 일러스트의 완성도와 함께, 여러 적이 모일 때의 식별성을 검수한다. 참고 게임의 속성·장비·도감 규칙은 자동으로 우리 기획에 추가하지 않는다.

다음 제작 기준

먼저 실제 게임 크기의 식물·좀비와 홈/전투 화면에서 비교한다. 선택 뒤 투명 배경 스프라이트·아이콘·버튼·배경·애니메이션을 분리 제작하고, 발밑 기준점·여백·배율·외곽선·그림자 방향을 통일한다. 레퍼런스의 얼굴·실루엣·소품을 새로 설계해 우리 게임의 정체성을 만든다.

카툰 가든 v1 · 실제 리소스로 보는 프리뷰

사용자 레퍼런스를 바탕으로 식물3종(팝피·벨라·메리), 좀비3종(모시·크룩·팟벨리), 온실1종의 개별 투명 PNG와 숲 배경을 제작했다.7개 투명 리소스는 모두 실제 RGBA 알파 채널을 확인했다. 확대도와 같은 PNG를 카드·전장에 직접 렌더링하는 홈·전투 프리뷰로 연결했다.

  • 중앙 온실·주변8칸·상단 상태·하단 구매 영역의 구성을 유지한다.
  • 프리뷰에서 드래그 배치·같은 꽃 합성·공격 범위·안착 모션을 확인한다.
  • 신규8개 리소스는 보관함에 검토 상태로 등록한다. 본편의 기존 병력 이미지는 아직 교체하지 않는다.
  • 온라인 관리에서 신규 리소스를 교체하면 같은 온라인 주소의 프리뷰가 해당 이미지를 사용한다. 공개 페이지는 별도 게시본이다.
  • 단일 포즈 PNG와 코드 모션으로 구성한 디자인 시뮬레이션이다. 본편의 전투 밸런스·저장·챕터 진행을 검증하는 구현은 아니다.
  • 걷기·공격·피격·사망의 개별 애니메이션 프레임, 성장 단계별 모델은 후속 제작 범위다.

카툰 가든 v2 · 파츠 애니메이션과 인게임 UI

사용자가 승인한 카툰 디자인을 기준으로 팝피8파츠·모시6파츠를 제작했다. 원본 단일 PNG 전체를 흔드는 방식에 더해 머리·몸통·팔·발과 무기의 회전 기준점을 나누고, 부모 관절의 이동·회전을 자식 파츠가 함께 받는2D 컷아웃 렌더러를 사용한다.

  • 팝피: 머리·몸통·팔2·발2·새총·씨앗. 대기·공격·피격을 비교한다.
  • 모시: 머리·몸통·팔2·다리2. 대기·걷기·공격·피격을 비교한다.
  • 파츠 시트는 전체 투명 PNG로 보존하고, 영역 좌표·회전 기준점·부모 연결은rigs.json에 기록한다.
  • 전장과 움직임 실험 화면이 동일한 리깅 렌더러를 공유한다.
  • 인게임 UI는 선택한 꽃 정보, 배치·합성 가능 안내, 햇빛 생산 진행 표시, 부족한 자원 표시, 일시정지·홈 복귀를 코드로 구현한다.
  • 벨라·메리·크룩·팟벨리는 아직 단일 PNG다. 나머지 병종 파츠·성장 모델·최종 공격 연출은 후속 범위다.
프리뷰 검토 범위

관절의 겹침, 작은 전장 크기에서의 식별성, 공격 동작과 투사체의 연결을 확인한다. 본편의 저장·챕터·능력치 설정은 이 시안과 분리해 유지하며, 프리뷰용 전투 반복 연출이 실제 밸런스 검증을 대신하지 않는다.
